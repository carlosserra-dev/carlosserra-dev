## Cases profissionais

Projetos de empresa, com código privado. Aqui estão a arquitetura e o resultado, sem dados de cliente.

### Plataforma de agentes de conteúdo (Ideatore / TD SYNNEX)

Plataforma web que gera conteúdo com IA para o blog, o e-mail marketing e os relatórios de performance. O Blog Agent roda um pipeline em etapas (pesquisa, redação, validação, links internos), com cada etapa checando a anterior. Já saíram 8 artigos, todos aprovados pelo cliente na primeira revisão. O Relatórios Agent funciona como um chat conectado via MCP à plataforma de relatórios, e responde com dados reais da conta em vez de texto genérico.

Node.js, Express, MCP, web search, deploy no Railway, autenticação por sessão, jobs assíncronos com polling, retry com backoff e controle de custo por tokens.

### Gerador de landing pages por fabricante (Ideatore / TD SYNNEX)

Gera landing pages e páginas de agradecimento por fabricante a partir de um briefing, no padrão visual e de SEO da conta, e entrega em formato pronto para publicar. Em produção.

### Agente de social media (cliente Ideatore)

Agente que cria e organiza conteúdo para redes sociais de uma conta de cliente, seguindo o tom de voz da marca.

### Analytics, GEO e segurança de tráfego (blog TD SYNNEX BR)

Análise de quanto tráfego chega por citações de IAs generativas e diagnóstico de tráfego de bot (datacenters e origem atípica) com GA4 e Cloudflare, incluindo as regras de WAF e rate limiting para mitigar. Também cuido de banners e de SEO/analytics do blog.
